21

借家権の第三者対抗力 — 「住んでいること」が看板になる

一言でいうと

借家人は、建物の引渡しを受けて住んでいること自体が借家権の公示となり、第三者に対抗できます（借地借家法31条）。登記をもらえなくても、自分の力だけで対抗力を備えられるのです。

お店の行列のたとえ：
遊園地の席取りを考えてください。「この席は私が予約しました」という紙（登記）を貼るには係員（家主）の協力が必要。でも、実際にその席に座っているなら、誰が見ても「この席は使用中だ」と分かります。
借家人は「座り続けること」（＝建物に住むこと）によって、係員の協力なしに、自分の権利を全世界に示せるのです。

なぜ「引渡し」が対抗要件になったのか

本来、不動産賃借権の対抗要件は賃借権の登記です（民605条）。しかし賃借権は債権なので、借家人には「登記してくれ」と請求する権利がなく、家主が協力してくれなければ登記できません。家主にとって賃借権の登記は物件の価値を下げるだけなので、現実にはまず協力してくれません。

民605条の登記
家主の協力が必要 → 現実には無理
→
借家人保護の必要
「売買は賃貸借を破る」では困る
→
借地借家法31条
建物の引渡し＝対抗要件

借家人が単独でできること

講義の核心はここです。借家人は、賃貸借契約に基づいて家主に建物の引渡しを請求できます。家主が任意に渡さなければ、訴訟を起こして勝訴判決を取り、強制執行で引き渡させることもできる。つまり「引渡しを受ける」ところまでは、家主の善意に頼らず、借家人が自力で（法的手続を通じて）実現できるのです。

建物賃貸借契約の締結
→
引渡請求権の発生
（債権）
→
任意の引渡し or 訴訟＋強制執行
→
引渡しを受けて居住
＝対抗力の取得

第三者から見るとどう見えるか

建物を買おうとする人や差し押さえようとする債権者は、取引の前に現地を見に行きます（建物の現認）。すると、家主ではない人が住んでいる。「あなた誰ですか？」「私は借家人です」— この時点で第三者は借家権の存在を知ることができる。これが「引渡し＝公示」の意味です。

📜 民法605条の登記

  • 不動産賃借権の本来の対抗要件
  • 登記には家主の協力が必要
  • 借家人に登記請求権はない
  • → 現実にはほぼ使えない
VS

🏠 借地借家法31条の引渡し

  • 建物賃貸借の特別な対抗要件
  • 住んでいる事実そのものが公示
  • 借家人が単独で備えられる
  • → 現実の借家人保護の柱
借地借家法31条：「建物の賃貸借は、その登記がなくても、建物の引渡しがあったときは、その後その建物について物権を取得した者に対し、その効力を生ずる。」
→ 家が売られても、差し押さえられても、引渡しを受けた借家人は新所有者・買受人に「住み続ける権利」を主張できる。いわゆる「売買は賃貸借を破る」原則の重大な修正です。
「住んでいれば常に勝てる」わけではありません。対抗力の優劣は時間の先後で決まります。
例：銀行が先に抵当権設定登記 → その後に借家人が入居 → 競売されたら借家人は買受人に対抗できない（原則6か月の明渡猶予があるだけ。民395条）。
「自分の対抗要件が、相手の対抗要件より先か後か」を常に確認するクセをつけましょう。
借地の場合との比較：借地権（建物所有目的の地上権・土地賃借権）の対抗要件は、借地上に自分名義で登記した建物を所有していることです（借地借家法10条）。土地は「住んで占有」を外から確認しにくいので、建物登記という形で公示します。借家＝引渡し、借地＝借地上建物の登記、とセットで覚えましょう。
Q1: 借家人Bが入居した後、家主Aが建物をCに売却した。CはBに「出て行け」と言えるか？
💬 解答例を見る

言えない。Bは建物の引渡しを受けているので、借地借家法31条により、その後に物権（所有権）を取得したCに借家権を対抗できる。Cは賃貸人の地位を引き継ぎ、BはCとの間で賃貸借を続けられる（Cが賃貸人の地位をBに主張して賃料請求するには、Cが所有権移転登記を備える必要がある点も実務上重要）。


Q2: なぜ民法605条の登記ではなく、借地借家法31条が借家人保護の柱になっているのか？
💬 解答例を見る

賃借権は債権にすぎず、借家人には登記請求権がないため、登記には家主の協力が不可欠だが、家主には協力する動機がない。これに対し建物の引渡しは、賃貸借契約に基づく引渡請求権の行使として、必要なら訴訟・強制執行を通じて借家人が単独で実現できる。自力で備えられる公示手段だからこそ、現実に機能する対抗要件となる。

22

所有権に基づく目的物返還請求の攻防：まとめ

一言でいうと

「物を返せ」をめぐる裁判は、①物権的請求 → ②占有権原の抗弁 → ③対抗要件による反撃という攻防のキャッチボールで進みます。講義11〜21で学んだ攻防を、ここで一枚の図にまとめます。

カードゲームのたとえ：
先攻（所有者）：「私の物をあなたが占有している。返せ！」（攻撃カード＝物権的返還請求権）
後攻（占有者）：「私には借りる権利がある！」（防御カード＝占有権原の抗弁）
先攻：「私の所有権には登記がある。あなたの権利は私に主張できないはずだ」（切り札＝対抗要件）
後攻：「こちらも引渡しという対抗要件を先に備えている！」（カウンター）
どちらのカードが強いかは、対抗要件を備えた順番で決まります。

物権的請求権の3類型

物権は目的物を直接支配する権利だから、その支配を邪魔する者に対し、邪魔の除去を請求できます。条文に明文はありませんが、当然の権利として認められています（占有訴権〔197条以下〕の存在と物権の性質から導かれます）。

類型場面請求内容占有訴権での対応物
返還請求権物を奪われた・占有されている「目的物を返せ」占有回収の訴え（200条）
妨害排除請求権占有以外の方法で侵害（隣の廃車が放置等）「侵害をやめろ・除去しろ」占有保持の訴え（198条）
妨害予防請求権侵害の具体的なおそれ（隣の崖が崩れそう等）「予防措置をとれ」占有保全の訴え（199条）

思維導図：返還請求の攻防まとめ
  • 所有権に基づく返還請求の攻防
    • 攻撃側（所有者X）
      • 物権の直接性 → 侵害者に侵害除去を請求できる
      • 主張すべきは「Xもと所有」＋「Y現占有」だけ
      • 占有権原の不存在まで証明する必要はない（相手が証明する）
    • 防御側（占有者Y）
      • 自分にも目的物を支配する法的根拠（権原）があると反論
      • 例：賃借権・地上権・質権・留置権・自分こそ所有者
    • 勝敗を決めるもの
      • Xの権利に第三者対抗要件 → 排他性が発現し請求を維持
      • Yの権原にも対抗要件 → 先に備えた方が勝つ
      • どちらも未具備 → お互いに対抗できず、膠着

対抗要件カタログ（ここまでの総整理）

権利対抗要件根拠条文
不動産物権（所有権・抵当権・地上権など）登記民177条
動産物権（所有権など）引渡し民178条
不動産賃借権（原則）賃借権の登記民605条
借地権借地上の自己名義の登記建物借地借家法10条
借家権建物の引渡し借地借家法31条
このまとめの核心は次の3文に凝縮されます。
① 物権者は、支配の直接性に基づいて侵害除去を請求できる。
② 相手方は、自分の権原に基づいて争うことができる。
③ 勝敗は、どちらが先に第三者対抗要件を備えたかで決まる。
この型は、この後の物権変動論（講義27〜30）でもそのまま使い回します。
「所有者は必ず勝つ」と思い込むのが初学者の典型的誤解です。
所有権は強力ですが、相手が正当な占有権原＋先順位の対抗要件を備えていれば、所有者の請求は通りません（例：対抗力ある借家人に新所有者が明渡請求しても負ける）。所有権の「絶対性」とは「誰にでも主張できる可能性がある」という意味であって、「常に勝つ」という意味ではありません。
Q1: 所有者Xが占有者Yに返還請求するとき、Xは「Yに占有する権利がないこと」を証明する必要があるか？
💬 解答例を見る

必要ない。Xが主張・立証すべき請求原因は「Xの所有」と「Yの現占有」のみ。占有権原の存在はYの側が抗弁として主張・立証する。権原の「不存在」という消極的事実の証明は困難であり、自分に有利な権原は持っている本人が一番証明しやすい、という公平の考え方に基づく役割分担である。


Q2: 物権的請求権の3類型を、隣人トラブルの具体例とともに挙げよ。
💬 解答例を見る

①返還請求権：隣人が勝手に自分の駐車場に車を停めて居座っている → 「土地を明け渡せ」。②妨害排除請求権：隣人の壊れたフェンスが自分の庭に倒れ込んでいる → 「撤去せよ」。③妨害予防請求権：隣人の石垣が今にも自分の敷地に崩れそう → 「補強工事をせよ」。

23

物権法の体系、占有権 — 物権は「カタログ注文制」

一言でいうと

物権は誰に対しても主張できる強力な権利なので、法律が用意したカタログの中からしか選べません（物権法定主義・民175条）。そのカタログの先頭に、ちょっと変わり者の「占有権」がいます。

レストランのたとえ：
債権＝個室での会食。当事者2人の間だけの話なので、メニューにない料理も「アレンジでお願いします」と自由に注文できる（契約自由）。
物権＝ホール全体に影響するBGMや照明。全てのお客さん（＝全世界）に影響するから、「メニュー表にある選択肢」からしか選べない。勝手に「オレ様専用照明権」を作られたら店内は大混乱。
これが物権法定主義です。

なぜ物権は法定主義で、債権は自由なのか

🏠 物権 → 法定主義（175条）

  • 対世的・絶対的な権利（全員に効く）
  • 勝手に新種を作ると社会が大混乱
  • 公示（登記・占有）の仕組みも種類が決まっていないと作れない
  • → 法律が決めた種類・内容だけ
VS

🤝 債権 → 非法定主義

  • 相対的な権利（当事者間だけで作用）
  • 変な内容でも困るのは当事者だけ
  • 第三者を巻き込まないから公示も原則不要
  • → 契約自由の原則で何でも作れる

物権のカタログ（民法物権編の体系）

思維導図：民法上の物権10種の体系
  • 物権（民法のカタログ＝10種）
    • 占有権（180条〜）🖐️
      • 「事実上支配している」こと自体を保護する特殊な物権
      • 正当な権利があるかどうかは問わない
    • 本権（占有を正当化する権利）
      • 所有権（206条〜）👑 — 全面的支配権
      • 制限物権 — 他人の所有物を限定的に支配
        • 用益物権（使う・収益する）
          • 地上権・永小作権・地役権・入会権
        • 担保物権（債権回収のために押さえる）
          • 留置権・先取特権・質権・抵当権

占有権 — 「事実状態」をなぜ保護するのか

占有権は、物を事実上支配しているという状態そのものに与えられる権利です。泥棒にすら占有権はあります。「正しいかどうか」を問わず、とにかく現にある支配状態を保護する — 一見奇妙ですが、深い理由があります。

占有保護の理由＝自力救済の禁止・社会の平和維持
「あいつは泥棒だから、実力で取り返してよい」を認めると、誰もが「自分が正しい」と主張して実力行使を始め、社会は暴力の応酬になります。
→ だから、たとえ真の権利者でも、実力で奪い返してはならず、裁判で取り返せ。現にある占有はひとまず保護する。これが占有制度の核心です。
占有訴権（197条〜202条）：占有を侵害された者が占有に基づいて起こせる訴え。
・占有回収の訴え（200条）：奪われた → 返せ
・占有保持の訴え（198条）：妨害されている → やめろ
・占有保全の訴え（199条）：妨害されそう → 予防せよ
本権（所有権など）の有無を問わず使えるのがポイント。さらに占有には、権利の推定（188条）、即時取得（192条）、取得時効（162条）の基礎になるなど、多くの役割があります。
占有権を「弱い所有権」と理解するのは誤りです。占有権と本権は次元の違う権利です。
占有の訴えで泥棒が勝つことすらあります（所有者が実力で奪い返した場合、泥棒からの占有回収の訴えが認められうる）。ただし所有者は別途、本権の訴え（所有権に基づく返還請求）で取り返せます（202条：占有の訴えと本権の訴えは互いに妨げない）。
Q1: 当事者が契約で「新型の物権」を作ることはできるか？
💬 解答例を見る

できない。物権は対世的・絶対的な権利であり、勝手に創設されると第三者・社会全体が不測の負担を受け、公示の仕組みも機能しなくなる。そこで民175条は「物権は、この法律その他の法律に定めるもののほか、創設することができない」と定める（物権法定主義）。当事者間で似た合意をしても、それは債権的な効力（当事者間でのみ有効）しか持たない。


Q2: 自転車を盗まれた所有者が、泥棒の家の前に停めてあるその自転車を勝手に持ち帰った。法的に問題はあるか？
💬 解答例を見る

問題がある。これは自力救済であり、原則として禁止される。泥棒にも占有権があり、泥棒から占有回収の訴え（200条）を起こされれば所有者が敗訴しうる。正しい手順は、所有権に基づく返還請求（本権の訴え）を裁判所に提起し、判決を得て強制執行すること。「権利があっても実力行使はダメ」が近代法の大原則。

24

所有権・用益物権 — 全面支配と「権能の切り出し」

一言でいうと

所有権は目的物を使用・収益・処分できる全面的支配権（民206条）。用益物権は、その所有権から「使用・収益」の部分だけを切り出して他人に与えた制限物権です。

ケーキのたとえ：
所有権＝ホールケーキを丸ごと持っている状態。食べる（使用）・売って儲ける（収益・処分）、すべて自由。
用益物権＝ホールケーキの一切れ（「使う・収益する」部分）を切り分けて他人に渡した状態。渡した分だけ自分の取り分は減るが、ケーキ全体の持ち主は依然として自分。
切り分けた一切れを返してもらえば（用益物権の消滅）、ケーキはまた丸ごとに戻る — これを所有権の弾力性といいます。

観念的支配 — 「持っていなくても支配している」

占有権が「事実上の支配」を保護するのに対し、所有権をはじめとする本権は観念的な支配秩序に属します。つまり、目的物を手元に置いていなくても、所有者は所有者。海外旅行中も、家を貸している間も、所有権は揺るぎません。事実上の支配（占有）と法律上の支配（所有権）は別次元 — 講義23からの連続テーマです。

所有権の3つの権能（民206条）

権能意味例（マンションの一室）
使用物を直接使って利益を得る自分で住む
収益物から果実（収穫物・賃料）を得る他人に貸して家賃を得る
処分物を売る・壊す・担保に入れる売却する、抵当権を設定する

用益物権4種のカタログ

思維導図：用益物権の4類型
  • 用益物権（他人の土地を使用収益する物権）
    • 地上権（265条〜）🏗️
      • 工作物・竹木の所有のために他人の土地を使う権利
      • 例：他人の土地の上に自分の建物を建てる、地下鉄・送電線（区分地上権）
    • 永小作権（270条〜）🌾
      • 小作料を払って他人の土地で耕作・牧畜をする権利
      • 現代ではほぼ使われていない（農地は賃貸借が中心）
    • 地役権（280条〜）🛤️
      • 自分の土地（要役地）の便益のために他人の土地（承役地）を使う権利
      • 例：通行地役権（隣地を通らせてもらう）、眺望・日照地役権
    • 入会権（263条・294条）🌲
      • 村落共同体がまとめて山林原野などを利用する慣習上の権利
      • 例：村人みんなで山のキノコ・薪を採る
制限物権の発想：「制限」されているのは所有権の側。
地上権が設定されると、所有者は自分の土地なのに使えなくなる（使用収益権能が地上権者に移っているから）。つまり制限物権とは、他人の所有権の権能の一部を、物権として直接握る権利です。だからこそ所有者の気が変わっても奪われない（債権たる賃借権との決定的な違い → 講義26へ）。
「所有権絶対」といっても無制限ではありません。206条自身が「法令の制限内において」と明記しています。建築基準法・都市計画法による建築制限、相隣関係（209条以下：隣地との調整ルール）など、現代の所有権は多くの枠の中にあります。
Q1: 地上権が消滅すると、土地所有権はどうなるか？
💬 解答例を見る

切り出されていた使用収益権能が所有権に戻り、所有権は自動的に完全な全面的支配権に復元する。これを所有権の弾力性という。ゴムボールがへこみ（制限物権の設定）から元の形に戻るイメージ。


Q2: 袋地（公道に接していない土地）の所有者が、隣地を通って公道に出たい。考えられる法的手段を2つ挙げよ。
💬 解答例を見る

①隣地所有者と合意して通行地役権を設定する（物権として安定、登記すれば隣地が売られても対抗可能）。②合意できなくても、袋地所有者には法律上当然に隣地通行権（公道に至るための他の土地の通行権・民210条）が認められる（ただし最も損害の少ない場所・方法に限られ、償金が必要）。

担保物権 — 債権回収のための物支配

一言でいうと

担保物権は「債権が満足する可能性を高める」ために他人の所有物を支配する物権です。使うためではなく、お金を回収するための物権 — ここが用益物権との根本的な違いです。

担保物権は「人質ならぬ物質（ものじち）」です。
友達にゲーム機を貸すとき「返してくれるまで君のレアカードは預かっておくよ」と言えば、友達は返す気になる（留置的効力）。
「返さなかったらこのカードを売って貸した分を回収するよ。他の友達より先にね」と言えれば、さらに安心（優先弁済的効力）。
この2つの力の組み合わせ方で、4種類の担保物権が生まれます。

2つの分類軸

軸①：どうやって成立するか

⚖️ 法定担保物権

一定の事実があれば法律上自動的に成立

  • 留置権（295条）
  • 先取特権（303条）
  • 契約不要。「公平のために法が与える」担保
VS

✍️ 約定担保物権

設定契約の効果として成立

  • 質権（342条）
  • 抵当権（369条）
  • 当事者が合意して設定する担保（金融取引の主役）

軸②：どんな効力を持つか

効力内容留置権先取特権質権抵当権
留置的効力債権が満足するまで物を返さなくてよい（心理的圧力で弁済を促す）✅❌✅❌
優先弁済的効力金銭執行で債権者平等原則を破り、他の債権者より先に回収できる❌※✅✅✅

※ 留置権に優先弁済権はないが、競売の買受人にも「払うまで渡さない」と言えるため（引受主義）、事実上優先回収できるという強みがある。

担保物権の全体マップ

思維導図：担保物権4種の体系
  • 担保物権（債権回収のための物権）
    • 法定担保物権（自動成立）
      • 留置権 🔒「直すまで渡さない」
        • 例：修理代金をもらうまで時計を返さない時計屋
      • 先取特権 🥇「この債権は特別に先取り」
        • 例：給料債権・葬式費用などは政策的に優先
    • 約定担保物権（契約で設定）
      • 質権 💍「預かる＋優先回収」
        • 占有移転が必要（345条）→ 設定者は使えなくなる
      • 抵当権 🏠「預からず優先回収」＝担保の女王
        • 非占有型 → 設定者は使い続けられる（講義9の復習）

担保物権に共通する4つの性質（通有性）

性質意味イメージ
付従性被担保債権がなければ担保物権もない。債権が消えれば担保も消える影は本体（債権）がないと存在できない
随伴性債権が譲渡されると担保物権もついていく飼い主（債権）が引っ越せば犬（担保）もついていく
不可分性債権全額の弁済を受けるまで、目的物の全部に効力が及ぶ9割返済しても担保は1ミリも縮まない
物上代位性目的物が金銭等に変わったら（保険金・売却代金）、それに効力が及ぶ（304条）担保物が「変身」しても追いかける
担保物権を理解するコツは「誰と戦うための権利か」を意識すること。
担保物権の本当の敵は債務者ではなく、他の債権者です。債務者の財産が足りなくなったとき（破産・競合）、債権者平等原則の行列を飛び越えて先に回収する — そのための権利。講義7〜10（破産・別除権）とつながる話です。
「留置権＝優先弁済あり」と覚え違いしないこと。留置権が持つのは留置的効力のみ（物上代位もなし）。逆に先取特権・抵当権は優先弁済的効力のみで留置的効力なし。両方持つのは質権だけです。
Q1: 時計店が修理代金未払いの客に時計の返還を拒んでいる。これは何という権利か。契約は必要か。
💬 解答例を見る

留置権（295条）。「その物に関して生じた債権」（修理代金債権）を有する者が、弁済を受けるまでその物を留置できる。法定担保物権なので、契約は不要。修理を依頼し時計を預けたという事実があれば法律上当然に成立する。


Q2: 抵当権付きの建物が火事で全焼し、所有者に火災保険金が支払われることになった。抵当権者はどうなるか？
💬 解答例を見る

目的物は滅失したが、抵当権者は物上代位性（372条・304条）により、所有者が受け取るべき火災保険金請求権の上に抵当権の効力を及ぼし、そこから優先弁済を受けられる。ただし保険金が所有者に払い渡される前に差押えが必要。

地上権の譲渡自由、賃借権の譲渡不自由 — 物権と債権、再び

一言でいうと

同じ「他人の土地を使う」権利でも、物権の地上権は自由に譲渡できるのに、債権の賃借権は賃貸人の承諾なしには譲渡できない（民612条）。この違いは、物権と債権の本質そのものから導かれます。

定期券とお友達パスのたとえ：
地上権（物権）＝記名なしの回数券。土地を「直接」支配する権利だから、誰が使おうと土地所有者の生活は変わらない。だから他人に売っても譲ってもOK。
賃借権（債権）＝「友達だから家に泊めてあげる」という約束。あなただから泊めるのであって、見知らぬ人に「泊まる権利を譲ったから」と来られたら困る。相手が誰かが決定的に重要。だから譲渡には承諾が必要。

なぜこの違いが生まれるのか — 定義に戻る

物権＝物を直接支配
他人の意思を介在させない
→
支配の実現に所有者の行為は不要
誰が地上権者でも所有者の負担は同じ
→
譲渡自由
処分権能は物権の内容そのもの
債権＝人に行為を請求
債務者の行為を通じて実現
→
「誰に使わせるか」は賃貸人の重大関心事
信頼関係が基礎
→
無断譲渡・転貸は禁止
民612条：承諾が必要

地上権 vs 賃借権 総合比較表

比較項目地上権（物権）賃借権（債権）
権利の性質土地を直接支配する用益物権賃貸人に「使わせろ」と請求する債権
譲渡✅ 自由（所有者の承諾不要）❌ 賃貸人の承諾が必要（612条1項）
転貸（また貸し）✅ 自由（土地を貸すことも可）❌ 賃貸人の承諾が必要（612条1項）
無断で譲渡・転貸したら—（そもそも自由）賃貸人は契約を解除できる（612条2項）

「処分の自由」は物権の本質に組み込まれている。
物権は他人の意思を介在させずに物を支配する権利。その権利を売るか・贈るか・担保に入れるかも、権利者が単独で決められる（所有者がどう思おうと関係ない）。
一方、債権の世界で勝手な「また貸し・譲渡」を許すと、賃貸人は見知らぬ人に自分の物を使われることになる。賃貸借は当事者の信頼関係を基礎とする継続的契約だから、相手の交代には承諾が要るのです。
では実際の土地利用はどうか？ 現実には地上権はほとんど使われず、圧倒的に賃借権です。なぜなら土地所有者にとって地上権は強すぎる（譲渡自由・登記義務あり・長期間戻ってこない）から、所有者が地上権設定に応じないのです。
その結果、立場の弱い賃借人を保護するために借地借家法が発達した（賃借権の物権化）— 講義21とつながります。また判例は、無断転貸でも背信行為と認めるに足りない特段の事情があれば解除を認めません（信頼関係破壊の法理）。
Q1: Bは地主Aから土地に地上権の設定を受けて建物を建てた。BはAの承諾なしに地上権をCに売却できるか？ 賃借権だったらどうか？
💬 解答例を見る

地上権なら承諾なしに売却できる。物権として土地を直接支配しており、処分の自由は権利内容そのものだから。賃借権ならAの承諾が必要（612条1項）。無断で譲渡しCに使わせると、Aは賃貸借契約を解除できる（同条2項）。ただし判例上、背信行為と認めるに足りない特段の事情があれば解除は認められない。


Q2: なぜ賃借権の無断譲渡が「解除」までできる重大事由とされるのか？
💬 解答例を見る

賃貸借は、賃貸人が「この人なら大事に使ってくれる・賃料を払ってくれる」という信頼に基づいて自分の財産を委ねる継続的契約だから。勝手に利用者が交代すれば、その信頼の基礎が崩れる。だから612条2項は無断譲渡・転貸を契約解除事由とした。逆にいえば、信頼が壊れていない場合（例：実質同一の家族・法人への承継）には解除を制限するのが信頼関係破壊の法理である。

物権変動論 — 意思主義・対抗要件主義・無権利の法理

一言でいうと

物権変動（所有権の移転など）の基本ルールは3つ。①意思表示だけで物権は移転する（意思主義・176条）、②ただし対抗要件がないと第三者に主張できない（対抗要件主義・177条/178条）、③無権利者からは権利を取得できない（無権利の法理）。この三点セットが物権変動論の土台です。

コンサートチケットのたとえ：
① 友達と「チケット譲るよ」「ありがとう」で合意 → その瞬間にチケットの権利はあなたのもの（意思主義：書類も儀式も不要）。
② でも入場ゲートで「私のです」と主張するには、チケットの名義書換が必要（対抗要件主義：登記・引渡しという「名義」がないと第三者には通用しない）。
③ そもそもチケットを持っていない人から「譲るよ」と言われても、何も手に入らない（無権利の法理：ない袖は振れぬ）。

三点セットの構造

思維導図：物権変動論の基本構造
  • 物権変動論
    • ① 意思主義（176条）
      • 物権変動は「当事者の意思表示のみ」によって効力を生ずる
      • 登記・引渡し・代金支払は効力発生の要件ではない
      • フランス法型（⇔ドイツは形式主義：登記してはじめて移転）
    • ② 対抗要件主義（177条・178条）
      • 不動産 → 登記がなければ第三者に対抗できない（177条）
      • 動産 → 引渡しがなければ第三者に対抗できない（178条）
      • 適用範囲は意思主義より広い：取得時効・相続等による物権変動にも適用
    • ③ 無権利の法理
      • 無権利者から権利を承継取得することはできない（当然の理屈）
      • 伝統的理解：無権利の法理が働く場面に177条の出番はない
      • 近年の例外的修正：94条2項類推・即時取得・相続法改正など、無権利者からの取得を認める場面が拡大

「対抗できない」とはどういう意味か

176条で所有権はすでに移転している。それなのに177条は「登記がなければ第三者に対抗できない」という。つまり日本民法では、権利の移転（当事者間）と権利の主張（第三者間）が切り離されています。

AB売買契約成立
176条：この瞬間に所有権はBへ
→
登記はまだAのまま
Bは所有者だが「裸の所有者」
→
AがCにも売却（二重譲渡）
Cが先に登記
→
177条：Cの勝ち
Bは登記なき所有権を対抗できない

無権利の法理と対抗要件主義の棲み分け

🚫 無権利の法理が働く場面

そもそも権利が無い人からの取得

  • 例：Aの土地の登記名義を勝手に自分に移したXから、Cが買った
  • Xは無権利 → Cは何も取得できない
  • 登記の有無は関係ない（登記に公信力なし）
VS

⚔️ 対抗要件主義が働く場面

権利がある人からの二重取得の競争

  • 例：所有者AがBとCの両方に売った
  • BもCも「権利者Aから」取得 → 両者とも有資格者
  • → 先に登記した方が勝つ（177条）
頭の中の判定手順：
Step1 「売主は権利者か？」→ Noなら無権利の法理。買主は原則何も取得できない（例外：94条2項類推〔虚偽の外観を信じた者の保護〕、動産の即時取得〔192条〕）。
Step2 「権利者からの取得者が複数いて競合しているか？」→ Yesなら177条/178条。対抗要件の先後で決着。
この順番で考えれば、物権変動の問題の9割は交通整理できます。
意思主義と対抗要件主義の適用範囲はズレています。対抗要件主義の方が広い。
取得時効や相続による物権変動は「意思表示による変動」ではない（176条の世界の外）が、それでも177条は適用される（判例：時効取得者も登記がなければ時効完成後の第三者に対抗できない）。「176条とセットの場面だけ177条」と思い込まないこと。
Q1: AB間で土地売買契約が成立したが、代金未払い・登記未了・引渡し未了である。所有権はどちらにあるか？
💬 解答例を見る

原則としてBにある。176条の意思主義により、物権変動は意思表示のみで効力を生じ、契約成立時に所有権は移転する（特約があれば別。実務では「代金完済時に移転」の特約が多い）。登記・引渡し・代金支払は移転の要件ではない。ただしBは登記を備えるまで、その所有権を第三者に対抗できない（177条）。


Q2: 登記名義を偽造で取得したX（無権利者）から土地を買ったCは、登記を信頼したのだから保護されないか？
💬 解答例を見る

原則として保護されない。無権利の法理により、無権利者Xから承継取得はできず、日本の登記には公信力がないから「登記を信じた」だけでは救済されない。例外的に、真の所有者A自身が虚偽の登記の作出・存続に関与・放置していた場合には、民94条2項の類推適用により善意のCが保護されることがある（帰責性ある者は虚偽の外観を信じた者に負ける）。

物権変動の当事者間「対抗」問題 — AB間では登記は要らない

一言でいうと

売主Aと買主Bの当事者間では、Bは登記がなくても所有権の取得を主張できます。AB間の所有権争いは176条（売買契約の事実）だけで決着し、177条の出番はありません。

プレゼントのたとえ：
誕生日に時計をプレゼントしてくれた友人が、後日「やっぱりあれは僕の時計だ。名義の書類がないだろう」と言い出したら？
「あなた自身が私にくれたんでしょう」の一言で終わりです。あげた本人が「書類がないから無効」と主張するのは筋が通らない。
対抗要件（登記）は第三者との競争のための装備であって、取引の相手方本人との間では不要なのです。

訴訟でどう現れるか — 法的三段論法で見る

Aが「あの土地は自分の所有物だ」とBに対し所有権確認の訴えを起こしたとします。Bの反撃は1つの事実を主張するだけで足ります。

Aの主張
「目的物はA所有」
→
Bの反論
「AB間で売買契約が締結された」
→
176条を適用
所有権はAからBへ移転
→
結論
Aはもはや無権利。Aの請求棄却
巧妙なポイント：Bが主張するのは「AB間で売買契約が締結された」という事実だけ。
「売買契約締結時にAが所有していたこと」は、A自身が「自分の所有だ」と主張しているのだから争いがない。そこに176条を適用すれば、法的三段論法により「所有権はAからBに移転し、Aは所有権を失った」という効果が導かれる。
Bは自分の登記を一切持ち出す必要がない。これが「当事者間に対抗問題なし」の意味です。

なぜ当事者間では登記不要なのか

思維導図：登記が要る相手・要らない相手
  • Bは誰に対して登記が必要か
    • 登記不要の相手
      • 売主A本人 — 自分で売っておいて争うのは筋違い
      • Aの相続人 — 売主の地位をそのまま承継した「当事者の延長」
      • 無権利者・不法占拠者 — そもそも競争の資格がない（→講義29）
    • 登記必要の相手（177条の「第三者」）
      • Aからの二重譲受人C
      • Aの債権者で目的物を差し押さえた者
      • Aから抵当権・賃借権の設定を受けた者
場面適用条文決め手
A vs B（売買の当事者間）176条のみ売買契約の締結という事実
B vs C（Aからの二重譲受人同士）176条＋177条登記の先後
B vs 無権利の占有者176条＋無権利の法理登記不要で勝てる（→講義29）
「登記がない＝何も主張できない」という思い込みは捨てましょう。
177条が「登記がなければ対抗できない」と言う相手は第三者だけ。しかもその「第三者」もすべての第三者ではなく、対抗要件の欠缺を主張する正当な利益を有する者に限られます（制限説・判例）。当事者・包括承継人・無権利者には、登記なしで堂々と所有権を主張できます。
Q1: AがBに土地を売却した後、Aが死亡してDが相続した。Dは「Bは登記がないから所有権を主張できない」と言えるか？
💬 解答例を見る

言えない。相続人Dは被相続人Aの法的地位を包括承継しており、売主Aと同一の「当事者」の立場に立つ。当事者間に177条の適用はないから、Bは登記なくしてDに所有権取得を対抗できる。Dは177条の「第三者」に当たらない。


Q2: 所有権確認訴訟でA（売主）がBに敗れるとき、Bはなぜ自分の登記を主張しなくてよいのか？
💬 解答例を見る

Bが「AB売買契約締結」の事実を主張すれば、Aがみずから主張する「Aの所有」と合わせて176条が適用され、所有権はAからBに移転しAは無権利になったという効果が三段論法で導かれるから。対抗要件（177条）は権利取得を第三者に主張するための要件であり、変動の当事者間では売買契約の効力（176条）だけで決着する。

29

所有権移転に対する「一般の第三者」と「特別の第三者」

一言でいうと

Aから買ったBが、目的物を占有する見知らぬDに返還請求するとき — Dがただの占有者（一般の第三者）なら、Bは登記がなくても勝てます。登記が必要になるのは、Dが正当な権利の取得を主張する「特別の第三者」であるときだけです。

徒競走のたとえ：
177条の「登記の競争」は、正式にエントリーした選手同士の徒競走です。
AからBへ、AからCへ — 同じスタートライン（権利者Aとの取引）に立った者同士なら、ゴールテープ（登記）を先に切った方が勝ち。
でも、エントリーもせずコースに寝転がっている人（不法占拠者）は、そもそも競争相手ではありません。Bは「先にゴールした証明書（登記）」を見せなくても、「どいてください」と言えるのです。

訴訟の場面設定

売主Aから売買契約により所有権を取得したはずのBが、目的物を現に占有しているDに対し、所有権に基づく返還請求の訴えを提起しました。

Bの請求原因
①Bもと所有 ②D現占有
→
①の中身
「Aもと所有＋AB売買契約締結」で立証
→
Dの出方次第で
勝負が分かれる
「現占有」の「現」とは：訴え提起時ではなく、事実審の口頭弁論終結時を意味します。判決はその時点の事実状態を基準に下されるからです。また、Bの「もと所有」は「Aもと所有＋AB売買契約締結」という2つの事実から、176条の適用によって導かれます（Aの所有→売買→Bへ移転、という法的三段論法）。

Dの正体による場合分け

思維導図：占有者Dは何者か？
  • Bの返還請求に対するDの立場
    • 一般の第三者（ただの第三者）
      • 不法占拠者・何の権原も主張できない者
      • Bの登記の欠缺を主張する正当な利益なし
      • → Bは登記なしで勝てる（177条の「第三者」に非ず）
    • 特別の第三者
      • 「自分もAから買った」（二重譲受人）
      • 「自分はAから借りている」（対抗力ある賃借人）
      • 「Aへの債権で差し押さえた」（差押債権者）
      • いずれも権利者Aとの取引・法的手続に基づく正当な利害関係
      • → Bは対抗要件（登記）を備えていなければ負けうる

177条「第三者」の制限説（判例）

177条の条文は単に「第三者」としか書いていませんが、判例（大連判明治41・12・15）は、これを「当事者及びその包括承継人以外の者で、登記の欠缺（けんけつ＝不存在）を主張する正当な利益を有する者」に限定しました（制限説）。
理由：177条は自由競争の競争者同士を登記の先後で序列づけるルール。競争に参加する資格すらない者（無権利者・不法占拠者・不法行為者）まで「登記がないだろう」と言えるとするのは、制度の趣旨に反するからです。

「第三者」に当たる者・当たらない者

177条の「第三者」に当たる（Bに登記が必要）当たらない（Bは登記なしで勝てる）
二重譲渡の譲受人C不法占拠者・不法行為者
目的物の差押債権者無権利者（偽造登記の名義人など）とその譲受人
対抗要件を備えた賃借人当事者（売主A）とその相続人（包括承継人）
地上権・抵当権の設定を受けた者背信的悪意者（→講義30）
「悪意者（Bへの売買を知っていた者）は第三者から除外される」と早合点しないこと。
177条の世界は自由競争なので、単なる悪意者は「第三者」に含まれます（善意悪意不問）。「Bが先に買ったのを知っていたが、自分が先に登記すれば勝てる」と考えて取引するのは、自由競争として許される。
除外されるのは、自由競争の枠を踏み外した背信的悪意者だけです（詳しくは講義30）。
Q1: Bが買った土地に不法占拠者Dが住み着いている。Bは登記未了だが、Dに明渡しを請求できるか？
💬 解答例を見る

請求できる。不法占拠者Dは、登記の欠缺を主張する正当な利益を有しないから177条の「第三者」に当たらない（制限説・判例）。Bは登記なくして所有権取得をDに対抗でき、所有権に基づく返還請求（明渡請求）が認められる。


Q2: 同じ占有者Dでも、「Aから賃借して対抗要件を備えている」と主張した場合、結論はどう変わるか？
💬 解答例を見る

Dは権利者Aとの取引に基づく正当な利害関係人（特別の第三者）となる。Dが対抗要件（借家なら引渡し・借地なら借地上建物の登記）を先に備えていれば、Bが後から登記を備えても、Dは賃借権をBに対抗でき、Bの明渡請求は棄却される。Dの正体が「ただの占有者」か「正当な権原と対抗要件を持つ者」かで、登記の要否と勝敗が逆転する。

30

対抗要件主義の使い方 — 自由競争のルールブック

一言でいうと

返還請求訴訟で占有者Dが「自分もAから買った」「Aから借りている」と言い出したら、それは「自分は特別な第三者だ」という宣言。ここから先は自由競争経済秩序のルール＝対抗要件の先後で勝敗が決まります。

椅子取りゲームのたとえ：
1つの土地（椅子）に、Aから権利を得た人が2人現れた。どちらも「Aと契約した」のは本当。でも椅子は1つ。
民法のルールは「契約を先にした者勝ち」ではなく「椅子に先に座った（＝登記を先に備えた）者勝ち」。
だから不動産取引のプロは、契約したらその足で法務局へ走るのです。

訴訟での攻防：Dの言い分の法的整理

B → D
所有権に基づく返還請求
→
D：「自分もAから買った」
or「Aから借りている」
→
「ただの第三者」ではなく
「特別な第三者だぞ」の宣言
→
対抗要件の先後勝負へ
177条の土俵が開く

パターン①：D「自分もAから買った」（二重譲渡）

🏃 B（第一買主）

  • Aと先に売買契約
  • 176条で所有権取得（したはず）
  • 登記：未了
VS

🏃 D（第二買主）

  • Aと後から売買契約
  • 同じく176条で取得（したはず）
  • 登記：具備

結論：先に登記を備えたDの勝ち。Bは177条により、登記なき所有権取得をDに対抗できません。Dが登記を備えた時点で、Bの所有権取得は確定的に否定されます（Bに残るのは、Aに対する債務不履行責任の追及＝損害賠償請求だけ）。

パターン②：D「Aから借りている」（賃借人）

Dが賃借権の対抗要件（建物の引渡し〔借地借家法31条〕など）をBの登記より先に備えていれば、DはBに賃借権を対抗でき、Bの明渡請求は棄却。逆にBの登記が先なら、Dは新所有者Bに賃借権を対抗できず、明渡しを免れません。講義21の知識がここで合流します。

なぜ「早い者勝ち（登記の先後）」が正当化されるのか

自由競争経済秩序がキーワード。
資本主義社会では、同じ物を複数人が欲しがって競うのは健全なこと。民法は「先に契約した者」を絶対視せず、「公示という社会的に確認可能な行為を先に完了した者」に勝たせることで、
① 取引に入る者は登記簿さえ見れば安心できる（取引の安全）
② 権利者には登記を急ぐインセンティブが働く（公示の促進）
という、社会全体にとって合理的な仕組みを実現しています。Dが「Bが先に買った」と知っていても（単純悪意）、先に登記すれば勝てるのは、この自由競争の枠内の行動だからです。

自由競争の限界：背信的悪意者排除論

思維導図：第二譲受人Dの主観による場合分け
  • 登記を先に備えた第二譲受人Dは勝てるか
    • 善意（AB売買を知らなかった）
      • → 勝てる。自由競争の正当な勝者
    • 単純悪意（知っていた）
      • → それでも勝てる。知った上で競争に参加するのは自由
    • 背信的悪意（知った上で害意・不当目的）
      • → 負ける。177条の「第三者」から排除（判例）
      • 例：Bを困らせて高値で売りつける目的だけで買った
      • 例：Bへの復讐目的、Aと共謀してBの権利を潰す目的
背信的悪意者排除論は「悪意者は負ける」というルールではない点を再確認。
単なる悪意は自由競争のうち。排除されるのは、登記制度を悪用してもっぱら他人を害するような、信義則（民1条2項）に反する者だけです。「自由競争の土俵で戦う資格すら無い者」というイメージで捉えましょう。

Q1: AがBに土地を売却後、その事実を知っているDにも売却し、Dが先に登記した。BはDに所有権を主張できるか？
💬 解答例を見る

原則として主張できない。Dは単純悪意者にすぎず、自由競争秩序の下では177条の「第三者」に含まれる。先に登記を備えたDが確定的に所有権を取得する。ただしDが、Bを害する目的で買い受けた等の背信的悪意者と評価される事情があれば、Dは「第三者」から排除され、Bは登記なくして対抗できる。


Q2: 二重譲渡で負けた第一買主Bは、泣き寝入りするしかないのか？
💬 解答例を見る

物権としての所有権は失うが、Aに対する債権は残る。AはBへの所有権移転義務を履行不能にしたのだから、Bは売買契約の債務不履行に基づき、契約を解除して支払済代金の返還を求め、あわせて損害賠償（民415条）を請求できる。「物権の競争に負けても、契約相手への債権的請求は別」— 物権と債権の二本柱がここでも効いている。


Q3: なぜ民法は「先に契約した者」ではなく「先に登記した者」を勝たせるのか？
💬 解答例を見る

契約は当事者間の出来事で外部からは見えないが、登記は誰でも確認できる公示だから。「登記簿を見れば権利関係が分かる」状態を保つことで取引の安全が実現し、権利者にも速やかな登記が促される。見えない契約の先後で決めると、取引に入る者は常に「先の買主がいるかも」と怯えることになり、自由な経済活動が萎縮してしまう。
