ロープの左端を引くのは「本当の権利者」（元の所有者・相続人）、右端を引くのは「事情を知らずに買った第三者」。
審判（民法）は基本ルールとして左側（本当の権利者）の勝ちと決めています（＝無権利の法理）。
でも、場面ごとに「特別ルール」が用意されていて、右側が勝てることがある——その特別ルールが 94条2項・95条4項・96条3項・545条1項ただし書・177条・899条の2・909条ただし書 です。
各講義は「この場面ではどの特別ルールが発動するか」を一つずつ確認していく作業です。

31

無権利の法理の使い方

一言でいうと

「持っていない人からは、買えない」。売主が無権利者なら、買主は登記を備えても所有権を取得できない——これが無権利の法理です。

友だちのゲーム機を勝手に「売る契約」をしても、ゲーム機の持ち主は変わりませんよね。
AがCのゲーム機を「Bに売るよ」と約束し、Bが代金を払い、「所有者B」というシールまで貼った（＝登記）。それでも持ち主はCのまま。
シール（登記）は魔法のアイテムではない。Aが無権利なら、A→Bのルートで権利が流れてくることはあり得ないのです。
法格言でいえば「何人も自己の有する以上の権利を他人に譲り渡すことはできない」。

基本事例

甲土地の所有者は
ずっとC
→
無権利者Aが
Bに甲土地を売却
→
Bが所有権移転登記を
備えてしまった
→
Cは登記の抹消を
Bに請求できる

Cの請求の法律構成：所有権に基づく妨害排除請求権を訴訟物として、Bに対し所有権移転登記の抹消登記手続を求める。Bの名義の登記は、Cの所有権の円満な実現を「妨害」している状態だからです。

思維導図：無権利の法理
  • 無権利の法理
    • 内容
      • 無権利者からは権利を承継取得できない
      • 登記を備えても結論は変わらない
      • → 日本の登記には「公信力」がない
    • 真の権利者Cの武器
      • 所有権に基づく妨害排除請求 → 抹消登記手続請求
      • 所有権に基づく返還請求 → 明渡請求（Bが占有する場合）
    • Bが助かる可能性（例外ルート）
      • 時効取得（162条）→ ただし「原始取得」
      • 94条2項（類推）など第三者保護規定 → 講義32以降
      • ※ 動産なら即時取得（192条）があるが、不動産にはない

承継取得 vs 原始取得

🔗 承継取得

前の人から権利を受け継ぐ

  • 例：売買、贈与、相続
  • 前主が無権利なら取得できない
  • 前主の権利の傷（抵当権など）も引き継ぐ
  • 比喩：バトンリレー（バトンがなければ渡せない）
VS

✨ 原始取得

自分のところで新しい権利が生まれる

  • 例：時効取得（162条）、即時取得（192条）
  • 前主が無権利でも取得できる
  • まっさらな権利を取得（反射的に旧所有権は消滅）
  • 比喩：自分で新しいバトンを作る
登記に公信力なし——これが日本の不動産法の大前提。
「登記簿にAが所有者と書いてあったから信じて買った」というだけでは、Bは保護されません。
だからこそ、第三者を救う特別規定（94条2項類推など）がどこまで使えるかが、講義32以降の大テーマになるのです。
「登記を備えた者が勝つ（177条）」と「無権利の法理」を混同しないこと。
177条の対抗問題は、双方とも有効な取引で権利を取得しうる立場にある場合（二重譲渡など）の優劣ルール。
一方がそもそも無権利なら、177条の出番はなく、登記の有無は無関係に真の権利者が勝ちます。
まず「両者は対抗関係か、それとも一方が無権利か」を見極めるのが第一歩。
Q1: 無権利者Aから甲土地を買ったBが移転登記を備えた。真の所有者Cは登記がなくてもBに勝てるか？
💬 解答例を見る

勝てる。Aは無権利者だから、BはAから所有権を承継取得できない（無権利の法理）。CとBは対抗関係（177条）に立たず、Bの登記は法的に無価値。Cは所有権に基づく妨害排除請求として抹消登記手続を請求できる。

💬 Q2: それでもBが甲土地の所有権を取得できる場合があるとすれば？（ヒント：原始取得）

Bが甲土地を所有の意思をもって平穏・公然に長期間占有を続ければ、取得時効（162条：善意無過失なら10年、それ以外は20年）により所有権を取得しうる。これは承継取得ではなく原始取得であり、Bのところで新しい所有権が誕生し、その反射として元のCの所有権が消滅する、という構造である。

法律行為の無効と第三者

一言でいうと

C→Aの売買契約が無効なら、Aは結局無権利者。A→Bの転売にも無権利の法理が貫徹され、Bは原則負けます。ただし虚偽表示（94条2項）の場面では善意の第三者Bが勝つ——これが最大の例外です。

C → A 売買
※実は無効
→
A → B 転売
→
CA間が無効なら
Aは無権利者
→
原則：Bも
取得できない
水道のたとえ：所有権という「水」は C → A → B というパイプを流れてきます。
CA間の契約が無効＝最初のパイプが最初から繋がっていなかった、ということ。
上流が繋がっていなければ、下流のBの蛇口から水（所有権）が出るはずがない。
——ところが94条2項は、「C自身がわざと偽物のパイプを設置して見せた」場合には、それを信じたBに水を届けてあげる、という特別配管なのです。

無効原因のいろいろ

無効原因条文例第三者保護
公序良俗違反90条愛人契約、暴利行為なし（誰に対しても無効）
強行法規違反91条参照法律の禁止に反する契約なし
心裡留保（相手方が悪意・有過失）93条1項ただし書冗談と知りつつ承諾あり（93条2項：善意の第三者）
虚偽表示94条1項差押え逃れの偽装売買あり（94条2項：善意の第三者）

94条2項 — 第三者保護の王様

CとAが通謀して「売ったことにする」偽装売買（虚偽表示）をした場合、CA間の売買は無効（94条1項）。しかし、その外観を信じてAから買った善意の第三者Bには、無効を対抗できない（94条2項）。Bとの関係では、CA間売買は有効として扱われ、Bは所有権を取得します。

思維導図：94条2項とその類推適用
  • 虚偽表示と第三者（94条）
    • 原則（1項）
      • 通謀虚偽表示は無効 → Aは無権利者
    • 例外（2項）：善意の第三者に無効を対抗できない
      • 趣旨：自ら虚偽の外観を作ったCの帰責性 ＋ Bの信頼保護
      • 「善意」＝虚偽表示の事実を知らないこと
      • 判例：無過失は不要、登記も不要とするのが基本
    • 94条2項の類推適用（重要！）
      • 通謀がなくても「虚偽の外観＋本人の帰責性＋第三者の信頼」があれば類推
      • 例：Cが知りながらA名義の登記を放置した場合
      • 外観作出への関与が弱い場合 → 94条2項＋110条の法意（善意無過失を要求）
      • → 公信力のない不動産登記を実質的に補う判例法理
94条2項の正当化の方程式：
権利者の帰責性（自分で嘘の外観を作った）× 第三者の信頼（外観を信じた）＝ 第三者の勝ち
この「帰責性 × 信頼」という発想（権利外観法理）は、これから何度も登場します。96条3項も、表見代理も、みんなこの方程式の仲間です。
90条（公序良俗違反）の無効には第三者保護規定がありません。
愛人契約で譲渡された不動産を事情を知らない第三者が買っても、保護されないのが原則。
「無効ならなんでも94条2項」ではなく、条文ごとに第三者保護の有無を確認する癖をつけましょう。理由はシンプルで、90条違反の場面では権利者に「外観を作った帰責性」という構図が当てはまらず、むしろ社会秩序のために効力を否定するからです。
Q1: Cは債権者の差押えを逃れるため、Aと示し合わせて甲土地をAに売ったことにし、A名義の登記をした。Aがこれを善意のBに転売した。CはBに登記の抹消を請求できるか？
💬 解答例を見る

請求できない。CA間の売買は通謀虚偽表示として無効（94条1項）だが、Bは虚偽表示について善意の第三者なので、Cは無効をBに対抗できない（94条2項）。Bとの関係では有効な売買として扱われ、Bは甲土地の所有権を取得する。

💬 Q2: CとAの通謀はなかったが、Cが勝手に作られたA名義の登記を知りながら長年放置していた場合は？

94条2項を直接適用はできない（通謀虚偽表示がない）が、「虚偽の外観（A名義登記）＋Cの帰責性（知りつつ放置）＋Bの信頼」が揃えば、判例は94条2項の類推適用により善意のBを保護する。Cの関与の度合いが弱い事案では94条2項と110条の法意を併用し、Bに善意無過失まで要求する判例もある。

法律行為の取消しと第三者

一言でいうと

取り消されると契約は「初めから無効」（遡及的無効・121条）。だからAは遡って無権利者になり、Bは原則負ける。ただし判例は、取消しの「後」に現れた第三者との関係を177条の対抗問題（登記の早い者勝ち）として処理します。

基本事例の構造

C → A 売買
（当時Cは真の所有者）
→
A → B 売買
→
CがCA間契約を
取消し
→
遡及的無効（121条）
Aは遡って無権利者に

取消しがなければ、CA間・AB間それぞれに176条が適用され、C→A→Bと所有権が順次移転します。Cが「甲土地は私の物」と主張しても、Bから「CA間売買による所有権喪失の抗弁」が出て、Cは負けるはずでした。ところが取消しによって、CA間の移転が遡って消える。ここから攻防が始まります。

取消しは「ビデオの巻き戻しボタン」。
押した瞬間、C→Aの所有権移転シーンが録画ごと消去され、「最初からAに渡っていなかった」ことになる（遡及効）。
でも現実世界では、巻き戻しボタンが押される前にBが登場していたかもしれないし、押された後に登場したかもしれない。
民法は、ボタンが押された時点より前にいた人（取消前の第三者）と、後から来た人（取消後の第三者）とで、扱いを変えるのです。

取消前の第三者 vs 取消後の第三者

⏪ 取消「前」の第三者

Bが買った後にCが取り消した

  • 枠組み：取消しの遡及効 → 無権利の法理
  • 原則：Cの勝ち
  • 例外：95条4項・96条3項（錯誤・詐欺なら善意無過失のBを保護）
  • 強迫・制限行為能力には保護規定なし → Bは負ける
VS

⏩ 取消「後」の第三者

Cが取り消した後にBが買った

  • 枠組み：177条の対抗問題（判例）
  • 取消しによりA→Cへ「復帰的物権変動」が起きたと観念
  • AからみてCとBへの二重譲渡類似の関係
  • → 先に登記を備えた方の勝ち（Bの善意・悪意は問わない）
思維導図：取消後の第三者はなぜ177条なのか
  • 取消後の第三者（判例：大判昭和17年）
    • 理論構成：復帰的物権変動
      • 取消しによって所有権がA→Cへ「戻る」変動が生じたと見る
      • 他方でAはBにも譲渡 → A起点の二重譲渡と同じ構図
      • C（取り戻す人）とB（買った人）は対抗関係 → 177条
    • 実質的理由
      • 取り消したCは、すぐ登記を取り戻せたはず
      • 登記を放置したCの怠慢 vs 登記を信じたB → Cだけを守る理由はない
    • 帰結
      • Bが先に登記 → Bの勝ち（悪意でもよい）
      • Cが先に登記回復 → Cの勝ち
時間軸で枠組みが切り替わる——これがこの講義の最重要ポイント。
取消し前：遡及的無効 → 無権利の法理（＋95条4項・96条3項の例外）
取消し後：復帰的物権変動 → 177条の対抗関係（登記の早い者勝ち）
答案では必ず「Bが現れたのは取消しの前か後か」を最初に確定させること。
「取り消したからCの勝ちで終わり」ではありません。
取消し後にCが登記を回復しないまま放置すると、登記名義は依然Aのまま。これを信じて買ったBに登記を先に備えられたら、取り消したはずのCが負けます。
教訓：取り消したら、すぐ登記を取り戻せ。権利の上に眠る者は保護されない。
Q1: CがAへの売買を詐欺を理由に取り消した。その1か月後、Aが登記名義を持っていることを利用してBに転売し、Bが移転登記を備えた。CとBはどちらが勝つか？
💬 解答例を見る

Bの勝ち。Bは取消後の第三者なので、判例の枠組みでは取消しによる復帰的物権変動（A→C）とAB間の譲渡が二重譲渡類似の対抗関係に立ち、177条により先に登記を備えたBが優先する。この場面では96条3項は使わない（96条3項は取消「前」の第三者を守る規定）。

💬 Q2: 同じ事案で、Bがまだ登記を備えていなかったら？

対抗関係では「登記を先に備えた者」が勝つので、双方未登記の間はどちらも所有権取得を相手に対抗できない状態。Cが先に抹消登記・回復登記を済ませればCの勝ち。だからこそ取消後の権利者は一刻も早く登記を回復すべきことになる。

取消権者に帰責性のある取消原因 — 錯誤・詐欺の特則

一言でいうと

取消原因には「取消権者に落ち度があるもの（錯誤・詐欺）」と「ないもの（強迫・制限行為能力）」があります。落ち度がある場面に限って、民法は善意無過失の第三者を守る特則（95条4項・96条3項）を置きました。

取消原因のカタログ

取消原因条文取消権者の帰責性取消前の第三者の保護
未成年者・成年被後見人・被保佐人・被補助人の行為5条・9条・13条・17条なし（保護されるべき弱者）なし（第三者は負ける）
強迫による意思表示96条1項なし（脅された被害者）なし（96条3項の対象外）
錯誤（重要な錯誤）95条1項あり（自分で勘違いした）あり：95条4項（善意無過失）
詐欺による意思表示96条1項あり（騙されたとはいえ自ら意思表示した）あり：96条3項（善意無過失）
学校で例えると——

錯誤・詐欺の人＝勘違いした人、うまい話に乗せられた人。気の毒だけど「あなたにも少し不注意があったよね」と言える。だから、何も知らずに巻き込まれた第三者との比較考量で、第三者の方を守ることがある。
帰責性の天秤——これが95条4項・96条3項の正体です。

💬 Q2: CがAに騙されて甲土地を売り、Aがそれを善意無過失のBに転売した。その後Cが詐欺取消しをした。Bは？

時効取得と第三者 — 「完成の前か後か」で世界が変わる

一言でいうと

長年占有して時効取得した人と、その土地を元の所有者から買った第三者の対決。判例ルールは明快で、時効完成「前」に現れた第三者には登記なしで勝てる。時効完成「後」に現れた第三者とは177条の対抗関係（登記の早い者勝ち）になります。

基本事例

Cが甲土地を
20年以上占有
＋
所有者Aが
甲土地をBに売却
→
BがCに
明渡請求
→
Cの抗弁：
時効取得による
所有権喪失

訴訟での攻防：Cは、①ある時点の占有と20年以上経過後の占有（占有継続は推定される：186条2項）、②時効援用の意思表示（145条）を主張すればよい。占有はそれだけで「所有の意思・平穏・公然」が推定されます（186条1項）。Cの時効取得は原始取得——Cのところで新しい所有権が生まれ、反射的に元の所有権が消滅します。

時効完成は「ゴールテープを切る瞬間」。
完成前にBが買った場合：Cはまだ走っている途中。ゴールした瞬間の土地の持ち主はもうBなので、Cは「Bの土地を時効取得した」ことになる。BとCは「元の所有者 vs 時効取得者」という当事者の関係——対抗問題ではないので、Cに登記は不要。
完成後にBが買った場合：Cはもうゴール済み（所有権取得済み）。その後にAがBに売った——これはAからCとBへの二重譲渡みたいな構図。だから177条で登記の早い者勝ち。
「ゴールの瞬間に誰が所有者だったか」だけを見ればいいのです。

⏪ 時効完成「前」の第三者B

  • CはBの所有権を時効取得する関係
  • CとBは当事者類似の関係（対抗問題でない）
  • → Cは登記なくしてBに時効取得を主張できる
  • 判例：最判昭41.11.22ほか確立
VS

⏩ 時効完成「後」の第三者B

  • 時効完成でA→C、売買でA→B
  • A起点の二重譲渡類似 → 177条
  • → 先に登記を備えた方の勝ち
  • 判例：大連判大14.7.8ほか確立
思維導図：時効と登記の判例ルール5点セット
  • 時効取得と第三者（判例法理）
    • ① 当事者間：登記不要
      • 時効取得者は元所有者に登記なしで主張できる
    • ② 完成前の第三者：登記不要
      • ①と同じく当事者類似の関係だから
    • ③ 完成後の第三者：177条（登記必要）
      • 二重譲渡類似 → 登記の先後で決まる
    • ④ 起算点は占有開始時に固定
      • 起算点を勝手に後ろにずらして「完成前の第三者」化することは許されない
    • ⑤ 敗れても再起動できる
      • 完成後の第三者の登記時点から、さらに時効期間占有を続ければ再度時効取得できる（最判昭36.7.20）
なぜ「起算点の固定」（ルール④）が大事か：
もし占有者が起算点を自由に選べたら、「Bの登記の後から数え始めたことにすれば、Bはいつでも完成前の第三者になる」＝登記ルール（③）が骨抜きになってしまう。
だから判例は「時効の基礎たる事実（占有）の開始時点」から数えることを強制し、③と④をセットで機能させています。ルールは単品でなく連動するシステムとして覚えること。
「時効取得は原始取得だから、登記の有無に関係なく常に勝てる」は誤り。
原始取得性は「前主の権利の瑕疵を引き継がない」という取得の性質の話。完成後の第三者との優劣は別問題で、判例は177条の対抗問題として処理します。
「原始取得＝無敵」と覚えてしまうのが初学者の典型的な落とし穴です。
Q1: Cの取得時効が完成した後、元所有者Aが甲土地をBに売却し、Bが移転登記を備えた。Cは時効取得をBに主張できるか？
💬 解答例を見る

主張できない（原則）。Bは時効完成後の第三者なので、CとBは二重譲渡類似の対抗関係に立ち、177条により先に登記を備えたBが優先する。ただしCがBの登記の時点からさらに時効期間（例：20年）占有を継続すれば、Bを起点とする再度の時効取得が可能（ルール⑤）。

💬 Q2: 逆に、Cの占有開始から15年目にAがBへ売却・登記移転し、その後Cの占有が通算20年に達した場合は？

Cの勝ち。Bは時効完成前の第三者であり、Cは「Bの所有権」を時効取得する当事者類似の関係に立つから、Cは登記なくしてBに時効取得を対抗できる。Bへの売却・登記があっても、Cの占有が中断されない限り時効は進行し続ける。

札（登記）に「全部B」と書いてあっても、札に魔法の力はない——講義31の原則がそのまま効いています。

💬 解答例を見る

💬 Q2: この事案で「DとCは177条の対抗関係だから先に登記したDの勝ち」という処理はなぜ間違い？

177条の対抗問題は、同一の前主から両立しえない権利を取得した者同士の優劣の問題。Cの持分はBを経由してDに移転する可能性がそもそもない（Bはその部分につき無権利）から、CとDは対抗関係に立たない。一方が無権利のときは無権利の法理で処理し、登記の先後は問わない——講義31の判別基準そのもの。

相続放棄と第三者 — 遡及効は絶対に貫く

一言でいうと

相続放棄をすると「初めから相続人でなかった」ことになります（939条）。判例はこの遡及効を絶対的なものとし、放棄の前後を問わず、第三者（差押債権者を含む）は登記なくして放棄の効果を否定できません。取消し・解除・遺産分割と違って「後の第三者は177条」という切り替えが起きないのが最大の特徴です。

基本事例（講義の事案）

Aが死亡
B・Cが共同相続（各1/2）
→
Bの債権者Dが
Bに代位して持分登記
→ Bの持分を差押え
＋
Bは有効に
相続放棄をしていた
→
Cが第三者異議の訴え
（民執38条）で
差押えの排除を求める

Bが放棄すると、Bは初めから相続人でなかったことになり、甲土地はCの単独所有（に遡って確定）。するとDが差し押さえた「Bの持分」は存在しない権利だったことになります。Cは、強制執行の目的物について所有権を有する第三者として、第三者異議の訴えで差押えの排除を求められるか——問題は、Cがこの結果（単独所有）を登記なしでDに主張できるか、です。

相続放棄は「最初からゲームに参加していなかった」宣言。
途中まで参加して抜ける（途中退場）のではなく、エントリー名簿から名前が消える。名簿から消えた人の「持ち点」を差し押さえても、そんな持ち点は最初から存在しなかったのだから空振りです。
取消しや解除では「巻き戻し後の世界でも、第三者保護や対抗問題の調整が入る」のに、相続放棄では調整なしの完全巻き戻し。それだけ「借金ごと相続を拒否する自由」を民法が重く見ているということです。

判例ルール：最判昭和42年1月20日

相続放棄 vs 遺産分割 — 同じ遡及効でも結論が逆

🚫 相続放棄（939条）

  • 遡及効は絶対的
  • 第三者保護規定なし
  • 放棄の前後を問わず、登記なくして第三者に対抗できる
  • 理由：①家裁の申述で時期・有無が画一的に明確 ②債務からの解放という制度趣旨を貫く必要
VS

🍰 遺産分割（909条）

  • 遡及効にただし書あり（分割前の第三者保護）
  • 分割後の第三者には対抗要件主義（899条の2・177条）
  • 法定相続分を超える取得は登記がないと負ける
  • 理由：分割は当事者の合意次第で内容も時期も外から見えにくく、取引の安全への配慮が必要 → 講義40へ
なぜ相続放棄だけ「絶対的遡及効」が許されるのか：
① 放棄は家庭裁判所への申述という公的手続で行われ、3か月の熟慮期間内（915条）と時期も限定されている → 仮装・遡及の濫用のおそれが小さい
② 放棄は借金（債務）からの解放を含む制度。第三者との調整で効果が骨抜きになると、相続人保護という制度目的が果たせない
③ 差押債権者Dは、Bの「持分」というもともと不確実な期待を当てにしただけ → 保護の必要性が相対的に低い
「遡及効のある制度は、後の第三者とは177条」という講義33・36のパターンを機械的に当てはめてはいけない場面がここ。
取消し・解除・遺産分割 → 「後」の第三者とは対抗関係になる。
相続放棄 → ならない（常に放棄側の勝ち）。
例外の例外こそ試験で問われます。「放棄は絶対」と一行で記憶に刻みましょう。
Q1: Bの相続放棄の「前」にDがBの持分を差し押さえていた場合と「後」に差し押さえた場合とで、結論は変わるか？
💬 解答例を見る

変わらない。判例（最判昭42.1.20参照）は相続放棄の遡及効（939条）を絶対的なものと解し、放棄者Bは初めから無権利だったことになるから、差押えの前後を問わず、Cは登記なくして単独所有をDに主張できる。Dの差押えは存在しない持分を対象とした空振りであり、Cは第三者異議の訴え（民執38条）で排除できる。

💬 Q2: 取消後・解除後の第三者は177条で処理するのに、放棄後の第三者にはなぜ177条を使わないのか？

取消し・解除では、いったん有効に権利を取得した者からの「復帰的物権変動」を観念でき、登記を回復しない権利者の怠慢も非難できる。これに対し相続放棄は、家裁への申述という画一的・公的な手続により短い熟慮期間内に行われ、効果として相続人資格自体が遡って消滅する。判例は939条の文言どおり「初めから相続人でなかった」ことを貫き、復帰的物権変動を観念しない。債務承継の拒否という制度趣旨の徹底もこの結論を支える。

遺産分割と第三者 — 分割の前か後かで二段構え

一言でいうと

遺産分割にも遡及効があります（909条本文）が、分割「前」の第三者は909条ただし書で、分割「後」の第三者は対抗要件主義（899条の2・177条）で守られます。相続放棄と違い、遺産分割の遡及効は第三者との関係で大幅に制限されるのです。

基本事例（講義の事案：分割後の第三者）

Aが死亡
B・C共同相続（各1/2）
その旨の相続登記済み
→
遺産分割で
甲土地はC単独所有に
→
Bが自己名義の持分を
Dに売却
→
C単独所有か
C・D共有か？

分割によりCは甲土地を単独所有したはず（909条本文：相続開始時に遡って効力発生）。しかしBの登記名義（持分1/2）が残っており、Dはそれを買った——CはDに「全部私の物」と言えるのか。Cが提起するのは所有権確認の訴えです。

遺産分割は「兄弟の話し合いによる陣地の引き直し」。
最初は法律が自動的に半分ずつ線を引いてくれた（法定相続分）。その後、話し合いで「この土地は全部C」と線を引き直した。
でも、この引き直しは兄弟の部屋の中で決めたことで、外の人には見えません。地図（登記）を書き換えないまま放っておいたら、古い地図を信じて「Bの陣地」を買う人が現れても文句は言えない。
だから民法は言います——「引き直した線は、地図（登記）に反映してはじめて外の人に主張できる」（899条の2）。

⏪ 分割「前」の第三者

例：分割前にBの持分をDが買い受けた

  • 根拠：909条ただし書「第三者の権利を害することができない」
  • 分割の遡及効はDに及ばない → Dの持分取得は有効のまま
  • 通説：Dには登記（権利保護要件）が必要
  • 善意・悪意は問わないと解されている
VS

⏩ 分割「後」の第三者

例：分割後にBの登記名義の持分をDが買い受けた（本講義の事案）

  • 根拠：899条の2第1項（＋判例：最判昭46.1.26は177条で処理）
  • Cの「法定相続分を超える部分」（Bの旧持分1/2）の取得は、登記がなければDに対抗できない
  • → 登記の早い者勝ち。Dが先に持分移転登記を備えればC・D共有に
